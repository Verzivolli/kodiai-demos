KodiAI demos

KodiAI is an AI assistant for Albanian construction engineering, in development. Each module below is published as a standalone live demo running on sample data: open one and try it, no account needed.

Built by Ani Verzivolli, civil engineer and self-taught developer, with AI coding agents (Claude Code) · LinkedIn · GitHub

KTP Search (RAG)

AI search over Albania's 24 technical design codes. Every answer cites the numbered clause it comes from, and citations are checked against the retrieved text.

Try: an example question, then ask a follow-up of your own (5 live questions per visitor).

Next.js · TypeScript · Postgres (PGlite) · DeepSeek via OpenRouter · 80-question eval

Open demo Code

BoQ Builder

Bill of Quantities editor on the official SIM price catalogue (2,290 analyses, 2,051 materials), with formulas, Excel import/export and the government-portal API payload.

Try: search C25/30, type =R1*2 in a quantity cell, open "SIM payload (JSON)".

Next.js · React · react-datasheet-grid · exceljs · 130 tests

Open demo

Structural Model Builder

3D structural model builder in the browser, with Eurocode 8 response-spectrum definitions, SAP2000/ETABS import and real OpenSeesPy results.

Try: open the Viewer tab (modes, base shear), then Examples → EC8 detailing and Design Checks.

JavaScript · Three.js · OpenSeesPy · Python validation

Open demo

Dossier Workspace

Generates the construction-phase document package (notices, conformity acts, site diary, acceptance reports) from one set of project fields: 26 templates.

Try: pick a phase and a document, then Download DOCX.

Next.js · TipTap/ProseMirror · docx · pdfmake · 204 tests

Open demo

Eurocode & KTP Calculators

22 structural calculators (EN1992/1993/1994/1997/1998 and Albanian KTP codes), each showing every step with its clause and formula.

Try: Punching shear or Retaining wall, and change the inputs.

Single static page · no backend · hand-checked notes per calculator

All demos run on sample data only; nothing you enter is stored or sent to KodiAI's database. KTP questions you type are sent to an AI model provider (OpenRouter) to be answered. The full application adds accounts, storage and the connection to Albania's SIM portal.
